# テキストエディタ
- ファイルを読み込みテキスト情報を表示すること、編集・入力した文字をファイルとして保存を行います。
- 文字色の変更とそれと独立してXMLのタグ要素(閉じタグの/を含む)の色を変更することができます
- XMLファイルであれば自動的にタグ要素はタグ要素として指定した色(デフォルトは青)で表示されます

## loadボタン
- 外部ファイルの読み込みを行います。
- 押下するとダイアログが表示されて、ファイルを選択できるようになっております。
- 何も押下しないと、メッセージボックスに注意メッセージが表示されます。

## saveボタン
- ラジオボタンで指定したエンコードで入力内容を外部ファイルに保存します。
- ディレクトリ内に該当するファイルが存在しない場合は、新規にファイルを作成します。

## 文字色変更ボタン
- 押下するとカラーダイアログを開き、指定した色に文字色変更します。

## タグ色変更ボタン
- XMLファイル読み込み時にタグ要素の色を指定した色に変更します。
